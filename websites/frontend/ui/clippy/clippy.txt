✂️ Clippy — CSS `clip-path` Shape Generator

Website: (https://bennettfeely.com/clippy/)

🎯 What is Clippy?

Clippy is a web-based tool by Bennett Feely that allows you to visually create complex CSS `clip-path` shapes. It’s a super useful utility for front-end developers who want to design non-rectangular elements like blobs, polygons, and custom UI components—without writing raw `clip-path` values manually.

🛠 Features:
- 🟢 Live shape preview and adjustment
- ⌨️ Auto-generated `clip-path` CSS code
- ✏️ Drag points to visually modify polygons
- 📐 Supports shapes like circle, ellipse, inset, polygon
- 🎨 Great for creative UI/UX, buttons, cards, images, etc.

📋 Why Use It?

- Save time writing `clip-path` by hand
- Quickly prototype unique UI sections or masks
- Learn how different `clip-path` functions work visually
- Easily copy-paste generated CSS into your project

🧪 Ideal For:
- Front-end developers
- UI/UX designers
- CSS learners and tinkerers
- Creative websites and web apps

✅ How to Use:
1. Go to (https://bennettfeely.com/clippy/)
2. Choose a shape or create a polygon
3. Adjust it visually using draggable handles
4. Copy the generated CSS from the box
5. Paste it into your stylesheet
