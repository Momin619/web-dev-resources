                            --JavaScript Console Methods Cheat Sheet--


1. console.log()
   - Basic logging
   - Example:
       console.log("Hello")
________________________________________________________________

2. console.error()
   - Show errors in red
   - Example:
       console.error("Error!")
________________________________________________________________

3. console.warn()
   - Warnings with yellow highlight
   - Example:
       console.warn("Be careful!")
________________________________________________________________

4. console.table()
   - Display arrays/objects in table format 📊
   - Example:
       console.table(users)
________________________________________________________________

5. console.time() / console.timeEnd()
   - Measure time taken ⏱
   - Example:
       console.time("load")
       // some task
       console.timeEnd("load")
________________________________________________________________

6. console.trace()
   - Show the function call stack 🔍
   - Example:
       console.trace()
________________________________________________________________

7. console.group() / console.groupEnd()
   - Group related logs together 👥
   - Example:
       console.group("User logs")
       console.log("Login success")
       console.groupEnd()
________________________________________________________________

8. console.clear()
   - Clear the console screen 🧼
   - Example:
       console.clear()
________________________________________________________________

9. console.count()
   - Count how many times a function runs 🔁
   - Example:
       console.count("Click")
________________________________________________________________

10. console.assert()
    - Log only if a condition is false ❗
    - Example:
        console.assert(2 > 3, "Fail")
________________________________________________________________

11. console.log({ variable })
    - Prints in the format { variable: value }
    - Example:
        let age = 17
        console.log({ age })
    - Output:
        { age: 17 }
________________________________________________________________

12. console.table(array)
    - Prints objects of array in table form 📊
    - Example:
        const users = [
          { name: "Momin", age: 12 },
          { name: "Ali", age: 22 },
          { name: "Akbar", age: 27 }
        ]
        console.table(users)

    - Output:
        ┌─────────┬─────────┬─────┐
        │ (index) │ name    │ age │
        ├─────────┼─────────┼─────┤
        │ 0       │ 'Momin' │ 12  │
        │ 1       │ 'Ali'   │ 22  │
        │ 2       │ 'Akbar' │ 27  │
        └─────────┴─────────┴─────┘
_______________________________________________________________

13. console.log(JSON.stringify(users, null, 2))
    - Prints objects in JSON format (easy to read) 📄
    - Example:
        const users = [
          { name: "Momin", age: 12 },
          { name: "Ali", age: 22 },
          { name: "Akbar", age: 27 }
        ]
        console.log(JSON.stringify(users, null, 2))

    - Output:
        [
          {
            "name": "Momin",
            "age": 12
          },
          {
            "name": "Ali",
            "age": 22
          },
          {
            "name": "Akbar",
            "age": 27
          }
        ]
________________________________________________________________


⚡ Quick Reference Summary
==========================

1. console.log()        → Basic logging
2. console.error()      → Show errors in red
3. console.warn()       → Show warnings in yellow
4. console.table()      → Display arrays/objects as tables
5. console.time()       → Start timer
6. console.timeEnd()    → End timer and log duration
7. console.trace()      → Show function call stack
8. console.group()      → Start a log group
9. console.groupEnd()   → End a log group
10. console.clear()     → Clear console
11. console.count()     → Count executions
12. console.assert()    → Log only if condition is false
13. console.log({ var })→ Log variable as { key: value }
14. console.table(arr)  → Display array in table format
15. console.log(JSON)   → Pretty-print JSON
