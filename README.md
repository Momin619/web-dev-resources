## 🤝 Contributing

Contributions are welcome! If you’d like to add new resources or improve existing ones:

1. Fork the repository
2. Create a new branch
   ```bash
   git checkout -b feature/add-resource
   ```
3. Commit your changes
   ```bash
   git commit -m "feat: add new developer resource"
   ```

4. Push to your fork
