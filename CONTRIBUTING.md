# Contributing Guidelines

Thank you for contributing to this repository.

---

## 📌 How to Contribute

1. Fork the repository
2. Create a new branch
3. Add your resource in the correct category
4. Follow existing formatting style
5. Submit a pull request

---

## 📁 Resource Format

All entries in resources/ must follow this structure:

Name:
URL:
Type:
Level:
Description:
Tags:
Free/Paid:

---

## 📚 Docs Format

All entries in docs/ must:

- Be explanation-based
- Include examples
- Avoid resource-style metadata

---

## 🚫 Do Not

- Add duplicate resources
- Break formatting style
- Add low-quality or irrelevant links

---

## 🎯 Goal

Maintain a clean, structured, and high-quality developer resource hub.
