# Code of Conduct

## 1. Purpose

This project is built as a structured, open knowledge base for developers. Its purpose is to help people learn, discover, and use high-quality development resources in an organized way.

This Code of Conduct defines expected behavior for anyone interacting with this repository.

---

## 2. Expected Behavior

All contributors and users should:

- Be respectful in all interactions
- Focus on improving the quality of the repository
- Follow the established structure and formatting rules
- Provide clear and useful contributions
- Be open to constructive feedback and suggestions
- Keep discussions relevant to the project

---

## 3. Unacceptable Behavior

The following behaviors are not allowed:

- Adding spam or irrelevant content
- Submitting low-quality or duplicate resources
- Disrupting the structure or formatting of files
- Using offensive, abusive, or disrespectful language
- Intentionally breaking contribution rules
- Promoting unrelated content or self-promotion without value

---

## 4. Contribution Responsibility

All contributors are responsible for:

- Ensuring accuracy of the information they add
- Following the correct format for resources and docs
- Placing content in the correct category
- Avoiding duplication of existing entries

Maintainers may reject or remove any contribution that does not meet these standards.

---

## 5. Maintainer Rights

Project maintainers reserve the right to:

- Remove or edit contributions that violate guidelines
- Ban contributors who repeatedly break rules
- Update structure or rules as the project evolves

---

## 6. Scope

This Code of Conduct applies to:

- GitHub issues
- Pull requests
- Discussions
- Any form of contribution or interaction with this repository

---

## 7. Goal

The goal of this project is to maintain a clean, structured, and high-quality developer resource hub that remains useful for learners and professionals.

Respect the structure. Respect the community. Keep it useful.
